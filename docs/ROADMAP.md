# Roadmap

## Текущее покрытие (восстановленные модули)
- GUI PySide6 и режимы FFmpeg.
- Контроль имени `e.001`, `e.312`.
- Telegram watcher, аудиопроверка, приоритетная папка.
- Раздельные смешанные очереди YouTube/VK.

## Следующая итерация
- Убрать временную перезапись `settings.json` из Telegram watcher.
- Атомарная публикация завершённых файлов (временный файл → rename).
- Lock каждого watcher/uploader.
- Загрузка очереди в SQLite; устойчивость к внезапному выключению Windows.
- Автоматическая очистка старых локальных медиа и логов.
- Повторы с экспоненциальной задержкой при сетевых сбоях.
- Отчёты об успешных публикациях с URL.
- Тестирование конфликтов планировщика.
- Поддержка ИИ-монтажа по текстовым правилам и автоматических субтитров — перспективная функция, в текущем исходном коде не реализована.
