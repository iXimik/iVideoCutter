# Планировщик задач Windows

Windows Task Scheduler запускает разные модули независимо. Примеры в `scripts/` используют папку скрипта и проектное `.venv`.

Пример разумной последовательности:

- 12:00 — `run_telegram_watcher.py`;
- 12:15 — `run_youtube_uploader.py`;
- 12:20 — `run_vk_uploader.py`.

Разделение времени позволяет Telegram скачать и нарезать видео до старта загрузчиков. Это **пример**, а не настройка, записанная в планировщик.

В задаче Windows задайте «Не запускать новый экземпляр» при уже работающем процессе. Для Telethon нельзя запускать два watcher на одной сессии (ошибка `database is locked`). Для YouTube/VK не запускайте параллельно два процесса одной платформы — JSON-state не поддерживает атомарные изменения нескольких процессов.

Политика публикации:

1. Планировщик запускает загрузчик.
2. Загрузчик проверяет `output/telegram_priority/`.
3. При наличии ожидающих видео публикует Telegram-видео.
4. В противном случае выбирает очередную пачку из обычных папок.
5. Завершает работу до следующего планового запуска.

YouTube ограничивает частоту/количество загрузок; ошибка ограничения должна оставлять файл ожидающим, а не помечать его загруженным.
